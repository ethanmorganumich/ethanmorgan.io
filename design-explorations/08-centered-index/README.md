# Centered index

This draft consolidates the strongest pieces of the two document explorations:

- a genuinely centered, narrower and denser document column;
- a far-left, compact index using compact Inter labels;
- left-aligned typography throughout;
- a modest name and short personal introduction inspired by Benji's editorial typography;
- a small inline phrase animation that sits inside the writing rather than becoming a hero;
- sections without a separate one-third label column or redundant headings;
- a single quiet rule above the footer;
- a cursor-responsive link color in shades of blue, with an animated underline;
- an active sidebar number that follows the current section in red; and
- a true Levenshtein edit sequence that alternates directions. It uses typing and backspace behavior only, so each transition begins where the prior one finished.

The content now uses details already present elsewhere on Ethan's site, but it remains easy to revise as the new homepage takes shape.
