A cursor with a memory

Ethan Morgan · Draft · Interface notes

A small detail

There’s a sentence on the homepage that changes while you read it. The obvious way to build that is to erase the sentence and type another one. It works, but there’s something more interesting about watching the text get edited.

A few characters survive. The caret moves back into the sentence, removes a letter, inserts another, and carries on. The next phrase grows out of the previous one.

I’m interested in useful software.

It’s a small enough interaction to sit inside a paragraph. But it gives the page something to discover.

Find the edits first

Levenshtein distance counts the minimum number of single-character insertions, deletions, and substitutions needed to turn one string into another. Matching characters don’t cost an edit.

For an animation, the useful part is the sequence of edits. To change cat into cut, only the middle letter needs to change. The other two letters stay in place:

cat → cut
      a → u

The implementation calculates a distance table and walks through it to recover a minimum-edit path. The animation then turns that path into visible caret movements and keystrokes.

Keep the caret’s place

The edit path alone doesn’t make the motion feel natural. A substitution counts as one edit in the algorithm, but on screen it becomes a backspace followed by a typed character.

// Backspace removes the character before the caret.
value = value.slice(0, caret - 1)
      + value.slice(caret);
caret -= 1;

The direction alternates between phrases. A right-to-left pass finishes at the beginning; the next pass works forward from there. That lets the caret keep its position instead of jumping back to a starting point between every sentence.

This minimizes character edits, not every cursor movement or keystroke. Timing is a separate choice: the pauses make the edit readable. With reduced motion enabled, the sentence simply stays still.

The little bit of continuity is the part worth keeping. You can see how one thought becomes another.
