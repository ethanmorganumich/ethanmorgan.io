# Concept 01 — Margin Notes (compact revision)

A compact editorial personal-site direction built around one idea: the page feels like a considered personal colophon that Ethan has lightly annotated by hand.

## Visual direction

- Warm cream paper rather than stark white.
- A narrow 780px reading column and dense two-column section rhythm make the page feel like an editorial note, not a large portfolio landing page.
- Confident serif typography is paired with restrained sans-serif utility text.
- Rust red is the only accent. There are no gradients, color washes, or pastel background splashes.
- Two small hand-drawn notes point toward the parts that matter.
- Thin rules and economical spacing keep work and writing legible without making the page feel sparse.

## Delight

Links receive a loose rust-red underline on hover or keyboard focus. Project links also change the handwritten aside beside the list, giving each item a tiny bit of personality. The interaction is optional enhancement: navigation, content, and visual hierarchy remain complete without JavaScript.

## Prototype notes

- All content is fictional placeholder copy.
- Static HTML, CSS, and a small vanilla JavaScript enhancement; no build step.
- Responsive layouts are included for desktop, tablet, and mobile.
- Keyboard focus, reduced-motion preferences, semantic landmarks, and a skip link are supported.

Open `index.html` directly or serve this directory with any static file server.
