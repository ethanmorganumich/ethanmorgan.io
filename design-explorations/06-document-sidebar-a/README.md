# Document sidebar — draft A

A refined personal homepage treated as a short, typeset document rather than a conventional portfolio landing page. The desktop layout keeps a narrow sticky index to the left of a centered reading column; on mobile that index becomes compact top navigation.

The design uses an almost-white warm paper, dark ink, one muted terracotta note, and carefully limited serif display type. There are deliberately no image areas, cards, dot grids, or time-based theming in this pass.

Two light interactions remain: important links receive a warm cursor-following glow and an underlined color response; the opening phrase slowly removes characters before typing a replacement. With JavaScript disabled the first phrase remains visible and all content/navigation works normally. Reduced-motion visitors receive the same static experience without animation or cursor glow.

Open `index.html` directly in a browser; no build step is required.
