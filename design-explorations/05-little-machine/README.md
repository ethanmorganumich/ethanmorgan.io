# Concept 05: Little Machine

This version is a compact personal desk note rather than a portfolio or company
landing page. One sheet of ruled paper holds a short introduction, a few
everyday details, and three ordinary links. The original little machine remains
as a doodle in the lower margin.

## Tone and composition

- One note, mostly contained in a single desktop viewport
- No site header, navigation bar, oversized hero, numbered sections, cards, or calls to action
- Fictional personal details: troublesome basil plants, a squeaky bike pedal,
  lentil soup, and a small software question
- Ruled paper on a cool green desk, with a sticky-note scrap and handwritten signoff
- The machine is secondary to the writing and feels like a drawing added while thinking

## Interaction

Three inline links gently wake different parts of the doodle:

- **short notes** lights the lamp;
- **small experiments** turns the wheels; and
- **write back** pulls the lever.

Clicking one briefly advances the paper strip. Hover and keyboard focus share
the same states. With JavaScript unavailable, the page remains a complete note
with conventional links and a static illustration. Reduced-motion preferences
remove the animated transitions.

Open `index.html` directly in a browser; there is no build step or dependency.
